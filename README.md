# Cuadro USI

App de turnos del equipo USI: cuadro anual de 16 semanas, quién trabaja cada día,
peticiones y cambios de turno, vacaciones, bajas y horas.

- Web instalable (PWA) publicada con GitHub Pages.
- Datos en Firebase (Firestore), con entrada por nombre y PIN.
- `firestore.rules`: reglas de seguridad de la base de datos.
